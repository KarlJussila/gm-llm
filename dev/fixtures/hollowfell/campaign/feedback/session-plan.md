# Session-plan standing guidance

- **Layer multiple mysteries and let the player choose which to pursue.** The player values meaningful choices about where to focus their attention. Connections between mysteries should be suggested, not confirmed — let the player feel the pull of an unresolved thread rather than having it resolved for them. (from S1)
- **Information should feel earned through engagement, not delivered through exposition.** The player wants to discover things by interacting with the world, not by receiving information dumps. Gate knowledge behind character action — asking questions, making checks, probing NPCs — so the reveal feels like a payoff, not a handout. (from S1)
